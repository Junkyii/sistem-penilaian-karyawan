# Kinerja UI

## Struktur

- `ui/` — frontend dashboard: HTML, CSS, JavaScript
- `docs/` — PRD, desain arsitektur, dan generator PDF

## Jalankan UI

```powershell
cd D:\coba-ui\ui
python -m http.server 8000
```

Buka `http://localhost:8000`.

## File utama

- `ui/index.html`
- `ui/styles.css`
- `ui/app.js`
- `docs/PRD-Sistem-Penilaian-Kinerja.md`
- `docs/DESAIN-ARSITEKTUR-MVP.md`
